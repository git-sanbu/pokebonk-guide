**Browser play links, beginner guides, controls and build planning for PokéBonk.**

PokéBonk Guide is an independent fan guide at **[pokebonk.top](https://pokebonk.top/)**. This repository is its public introduction and a place to report guide corrections. The website brings together a game launch window, first-run advice and references you can read before playing.

## Start here

1. **New to PokéBonk?** Read the [beginner guide](https://pokebonk.top/guide) for guest access, accounts and first steps.
2. **Ready to try a run?** Open the [guide homepage](https://pokebonk.top/) and choose **Load game**, or visit [the original game](https://pokebonk.com/) directly.
3. **An input or loading problem?** Check [controls and troubleshooting](https://pokebonk.top/mechanics).
4. **Comparing upgrades?** Read [build planning](https://pokebonk.top/damage-build) for how to compare moves, upgrades and evolution requirements.

The original game may require a security check. If it cannot complete inside the embedded window, open the game in its own tab.

## Quick keyboard reference

These bindings reflect the public game interface reviewed by the guide on October 22, 2026. Check the current in-game interface if a control changes.

| Input | Documented action |
| --- | --- |
| WASD | Move |
| Mouse | Move the camera |
| Space | Jump / glide |
| Shift | Slide |
| R | Ultimate ability |
| E | Interact |
| Q | Aim |
| Right mouse button | Lock target |
| Mouse wheel | Zoom |
| Esc or P | Pause |

Click inside the loaded game before using the keyboard. Accounts and saves are managed by the original game service; guide editors cannot recover progress.
