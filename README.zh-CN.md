# PokéBonk Guide：在线入口与新手攻略

**推荐从 [pokebonk.top](https://pokebonk.top/) 开始：先看入门和操作说明，再打开游戏尝试一局。**

[访问网站](https://pokebonk.top/zh) · [English](README.md)

PokéBonk Guide 是一个独立的玩家攻略站，提供 PokéBonk 的浏览器游戏入口、新手说明、操作参考和配装思路。本仓库用于介绍网站和收集攻略纠错。

## 适合什么时候用

- **第一次接触游戏：** 阅读[新手攻略](https://pokebonk.top/zh/guide)，了解游客入口、账号和开局步骤。
- **想直接体验：** 在[首页](https://pokebonk.top/zh)点击加载游戏，也可以打开[原游戏网站](https://pokebonk.com/)。
- **不清楚按键或页面加载失败：** 查看[操作与排障](https://pokebonk.top/zh/mechanics)。
- **不知道如何选招式、升级或进化：** 参考[配装思路](https://pokebonk.top/zh/damage-build)，结合游戏内当前说明判断。

网站支持英语、简体中文、繁体中文和韩语，可通过语言菜单切换。

## 使用提醒

游戏可能要求安全验证；如果内嵌窗口无法完成，请在新标签页直接打开原游戏。账号与存档由原游戏服务管理，攻略站无法恢复游戏进度。

## 纠错与反馈

欢迎[提交 Issue](https://github.com/git-sanbu/pokebonk-guide/issues/new)，注明攻略页面链接、需要核对的内容，以及参考来源或复现步骤。不要在公开反馈中提供密码等私人账号信息。也可以通过[网站联系页](https://pokebonk.top/zh/about#contact)联系编辑。
